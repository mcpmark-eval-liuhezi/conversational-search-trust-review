# conversational-search-trust-review

A literature review of human trust in health information from conversational (LLM-powered) search agents and dissemination interfaces.

## Focus paper

**From Search Agents to Dissemination Interfaces: Understanding Human Trust in Health Information from Conversational Search**

- arXiv: [2608.21177](https://arxiv.org/abs/2608.21177) (cs.HC)
- Sun, Ma, Zhao, Lindqvist, de Wit, Li, El Ali & Bosch
- Accepted at *Behaviour & Information Technology (BIT)*

## Structure

- `papers/` — per-paper reading notes, one file per paper, named by arXiv ID (e.g. `papers/2608.21177.md`).
- Issues — one tracking "Digest" issue per paper, with follow-up sub-issues for the next steps the paper suggests.

## Why this project

LLM-powered conversational agents are replacing list-of-links search as the default way many people look up health information. How much people *trust* that information — and whether the interface that delivers it (text, speech, embodied) changes that trust — is the core question this review follows.
